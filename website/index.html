Website Build Portfolio [Page in Progress - Continuation following midterms]

A living record of the work behind this site — decisions, dead-ends, and the wins that shipped.

This project began simply as a project portfolio to highlight my professional progress on the web. The critical choice to build it from scratch using HTML, CSS, and vanilla JavaScript came naturally as I enjoyed learning by doing. Teaching myself lightbox, UX principles, and user led design through trial and error (more commits than I care to admit) has been incredibly rewarding. This website is now a sandbox for all my ideas and a place to test the theory learned from my life experiences.

My Current Thoughts on the project [2026-01-11]

I really haven't benefitted from this website as I had hoped. I have been on and off creating this website since I started my networking journey this past summer. I thought having a personal website would be a great way to showcase my skills and projects to potential employers but find the system I am up against is much more rigid than I had assumed. Nevertheless, I have learned a lot about web design, HTML, CSS, and JavaScript. I have also learned a lot about UX design and user-led design principles which I hope will be helpful to my future career or personal business. That is all for now, hopefully I can continue to build this out in the future with my final addition being the SEO of this website as well as britneybuttonevents.ca for my sister.

Prediction Markets Pipeline (Updated thoughts) [2026-03-16]

I could not have been more wrong. The last entry was before the tight recruiting season of some banks as well as a select few competitive consulting teams. These teams all value creativity slightly less than myself and therefore I was quite disapointed in my intern success. That said, I was hired shortly after by Questrade which provided some retribution to the time that had been put into product design and UX. Since then I have put the entire site on hold and entirely focused into school as well as the prediction markets project which has been interesting but time consuming in a world with little time. As I write this I am experimenting with perplexity computer (agent) in making a regression testing bot that can hopefully find correlation at the least (obvious) and causation at the best (unlikely) to go into the summer with a great understanding of the landscape and potentially a working starting point.
