Project Roadmap

Automated Causality Bot
Final Goal: An automated, continuous data engine that maps prediction market data (Polymarket) to traditional financial securities (Indices, Securities, Crypto, ETF's). The agent will programmatically filter for liquidity, handle collinearity via LASSO regression, and output a mathematically verified, unified composite trading indicator for each security.

The Architecture Plan

Phase 1: Data Discovery & Semantic Mapping
Fetch Active Markets & Cache

Continuously pull the master list of active markets. Store matched pairs in a cache to optimize API speeds and reduce double counting.

AI Ticker Filtering/Matching

Pass market questions through an AI API to infer and pair their corresponding financial asset based on market assumptions.

Phase 2: Quality Control & Data Ingestion
Liquidity Filtering & History

Query the CLOB to discard markets failing 24h volume thresholds. Fetch and pair high-frequency price data for both assets.

Phase 3: The Statistical Verification Engine
Time-Series Alignment & Correlation

Standardize timestamps. Run a maximum cross-correlation test across shifted timeframes to identify potential lead-lag relationships.

LASSO Regression (Tandem Test)

Feed all surviving trades simultaneously into a LASSO regression model to penalize redundancy and isolate the strongest predictive signals.

Phase 4: Output & Automation
Live Composite & Master Matrix

Log verified trades and Beta coefficients into a master matrix. Generate a real-time sentiment score by multiplying against live odds.
